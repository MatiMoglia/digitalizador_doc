# 📄 Sistema de Digitalización de Documentos

El **Sistema de Digitalización de Documentos** es una aplicación de escritorio desarrollada con **Electron**, con frontend en **Vue**, que permite generar, administrar y exportar documentación digital de forma simple, rápida y ordenada.

Está pensada para entornos administrativos (en este caso Servicios Sociales) donde se requiere:
- Reducir el uso de papel
- Centralizar documentos
- Generar constancias y reportes en formato digital

---

# Descargar el sistema

El instalador de la aplicación está disponible en la sección **Releases** del repositorio.
No es necesario instalar Node.js ni ejecutar comandos para utilizar el sistema.  
Solo descargue el archivo `.exe` y ejecute el instalador.
